Artefatos de gestão ágil do projeto **Clínica Mais Saúde**. Documentam o planejamento e a condução do
desenvolvimento (abr–set/2026), servindo de base para a seção de metodologia da monografia.

## Método

O projeto foi conduzido em **fluxo incremental contínuo** (estilo Kanban), com entregas frequentes de
software funcionando a cada tema/fase — não em *sprints* de duração fixa. O agrupamento em sprints nos
documentos é uma leitura organizada *a posteriori*, derivada do histórico de commits (222 commits), para
fins de documentação acadêmica.
